STANDALONE ENGINE

Key-value core

Implemented
  • Concurrency-safe CRUDMap-backed store with an RWMutex. Empty values supported.
  • Deterministic ApplyJSON PUT, GET and DELETE commands with defined results.
  • Versioned snapshotsComplete KV state in a repeatable version-1 JSON payload.
  • Atomic replacement restoreValidates first; invalid snapshots leave state unchanged.
  • Model & replay tests100 seeds × 200 commands, compared with a reference map.
  • Isolation & interface harnessNo Raft/network imports; tested through StateMachine.
Local checks passed. This console demonstrates the actual standalone engine.
